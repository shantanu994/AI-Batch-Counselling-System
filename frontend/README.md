# Frontend

React frontend for AI-Driven Batch Counselling System.

## Features

- Premium responsive dashboard UI
- Role-based screens (Admin, Counsellor, Student)
- Student and batch management modules
- Charts for performance and attendance analytics
- Dark mode toggle
- Loading states and error handling

## Setup

1. Copy `.env.example` to `.env`
2. Install dependencies

```bash
npm install
```

3. Run application

```bash
npm start
```

Open `http://localhost:3000`.
